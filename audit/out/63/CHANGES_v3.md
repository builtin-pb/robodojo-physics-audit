## 1. Joint static/kinetic unary friction (`feasibility.json`)

- One LP per cell now carries both fields and `u_kinetic[c] <= u_static[c]` for all 20 classes in the rows, including `mixed_unclear` (its 22 placeholder pairs are in), the pads, the tables and the ground. Stage 1 maximises the common margin, stage 2 the static margin with kinetic held, stage 3 the kinetic margin with static held. Margins are in effective-friction units (the realised pair coefficient), not pair sums.
- Check against the review: with the v2 aluminium–steel band restored, the solver gives static 0.025 / kinetic 0.05 under ground=average and 0.0 under multiply, feasible in 12/12 cells, critical rows aluminium__aluminium, steel__steel, aluminium__steel: the review's joint-LP numbers.

Both stay `estimated`: the row is bare aluminium, the class is anodised or coated alloy.
- Result: all 12 cells feasible. Ground set to average: static margin 0.05, kinetic 0.075 in every surface combination, no single critical row (v2: 0.025 and 0.05 in these units). Ground as shipped (multiply, unary 1.0): static 0.0, critical row `glass__glass` against the unsourced `glass__ground` placeholder, as in v2; kinetic 0.05. No class has `u_k > u_s` in any cell (asserted).
- The unary map in `class_values.json` is now labelled a feasibility certificate, not a recommendation. Bottle 00022 override interval for its actual partners: static [0.30, 0.70], kinetic [0.20, 0.65]; PR #84's 0.34 / 0.28 lies inside.
