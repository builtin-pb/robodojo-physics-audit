# Predictions for Evaluator v2 per-step stillness (#130), written before any code or witness run

## Rule under test

Under Evaluator v2 (`is_v2 == True`), stateful per-step movement predicates (`is_moved`, `is_not_moved`, `is_functional_point_moved`, `is_functional_point_not_moved` with `update=True`) compare each object's current pose or active functional points against one per-step reference snapshot of the previous action's pose:

1. **Episode start (`Func_Parser.init_state`, action 0):** after `setup_scene` settles the layout and before action 1 executes, `StillnessSnapshotV2` records every `Rigid`, `Articulation`, and `Garment` object's pose (and any `Articulation` active-functional `base_link` poses) as both `init_ref` and the initial `step_ref` / `pending_ref`.
2. **Start of each step (`RewardManager.step` -> `Func_Parser.begin_step_stillness_v2`):** once per step, before any `query`, `check`, `score`, `trigger_check`, or `trigger_query` predicate runs, `step_ref` advances to the previous step's snapshot (`pending_ref`), and `pending_ref` records the current step's poses for the next step.
3. **First action of an episode (action 1):** `step_ref` is `init_ref` (action 0, post-settle). Thus action 1 measures displacement over action 1 itself (`||p_1 - p_0||`): an object at rest during action 1 (`<= dis_threshold`) passes stillness; an object that moves or teleports `> dis_threshold` during action 1 fails stillness on action 1 and passes only after a subsequent action in which it moves `<= dis_threshold`.
4. **Within a step:** evaluating a predicate never mutates `step_ref`, so asking the same term twice in one step returns the same value, and asking a term for the first time at step `k` compares against step `k - 1` instead of passing by default.
5. **Evaluator v1 (`is_v2 == False`) and `update=False`:** `v1` executes the exact shipped code path untouched; `is_moved(..., update=False)` continues to compare against `pre_state[env_idx][inst_name]["pose"]` under both `v1` and `v2`. `EpisodeLedger.build_result_dict` records `"stillness_rule": "previous_action_snapshot"`.
